# Sangmeshwar Naik — Portfolio

A responsive, animated personal portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Import this folder/repository into Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.

## Personalization notes
- CV is included at `public/Sangmeshwar_Naik_CV.pdf` and linked from the hero.
- Replace the GitHub profile links on project cards with each project's exact repository URL when available.
- Contact form is intentionally a direct email link (no backend/API key required).
- The project descriptions and education details are based on the supplied CV.
